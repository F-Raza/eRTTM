eRTTM Leak Detection & Location

Transient-Model Algorithm: two transient models run in parallel on the same pipeline, each driven by different real boundary sensors. A leak makes them diverge from the real pipe, and the ratio of their inlet and outlet mismatches gives the leak location.

API standards: RTTM and E-RTTM leak detection as described in API RP 1130 (Computational Pipeline Monitoring for Liquids); see also API TR 1149 (leak detectability and variable uncertainties) and API RP 1175 (Pipeline Leak Detection – Program Management).

Wave propagation, pressure and flow profiles

UF = flow and UP = pressure difference at each end, compared with the model that is not driven by that quantity. UF inlet is real minus PQ model; UF outlet, UP inlet and UP outlet are model minus real (QP, QP and PQ model respectively). Volume balance is measured inlet flow minus outlet flow. The leak alarm is raised when both UF inlet and UF outlet exceed 50 % of the leak rate; leak size is calculated and shown as soon as the alarm is raised (from the inlet minus outlet flow balance); leak location is published once the models have settled. When the QP and PQ pressure profiles intersect, the crossing is the mirror image of the leak about the pipe mid-point: crossing = L − leak location.

Procedure

1 · Leak wave travels both ways

At t = 0 the leak starts and sends a pressure wave in both directions at about 1 km/s. Until it reaches a sensor, the real readings are unchanged, so both models still agree with the pipe.

2 · First sensor sees the wave

The sensor nearest the leak changes its Q or P. That new boundary data sends a wave into the models from that end, while the far end is still unaware of the leak.

3 · Second sensor sees the wave

The far sensor now changes too. Model waves travel inward from both ends and the QP and PQ profiles split away from the real profile.

4 · Models settle & leak is located

The QP model (inlet flow, outlet pressure) is off at the inlet, and the PQ model (inlet pressure, outlet flow) is off at the outlet. The ratio of the two pressure differences (UP inlet, UP outlet) gives the leak position. Where the QP and PQ pressure profiles intersect is the mirror image of that position about the pipe mid-point.

Role of the key inputs

Leak location

The location sets when each sensor sees the wave: distance ÷ wave speed (x/a at the inlet, (L−x)/a at the outlet). It also sets how the pressure drop is shared between the inlet and outlet, which is what the estimate reads back.

Leak size

The leak rate (as a % of flow) sets how much the flow differs on either side of the leak, and therefore how large the model mismatches become. Size scales both UP values together, so it changes their magnitude but not their ratio, and the location estimate stays the same.

QP and PQ models

The QP model takes inlet flow and outlet pressure from the real sensors; the PQ model takes inlet pressure and outlet flow. Each learns about the leak only when its own boundary sensors do, so they respond differently and disagree with the pipe in opposite places.

Location estimate

Once settled, UP inlet and UP outlet are combined: estimated location = pipe length × |UP outlet| ÷ (|UP inlet| + |UP outlet|). The QP and PQ pressure profiles intersect at pipe length − this location, so the crossing is a mirror image of the leak, not the leak itself.
